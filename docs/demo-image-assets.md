# بسته تصاویر نمایشی فروشگاه

برای طراحی و آماده‌سازی تصاویر نمونه، بسته‌ای از تصاویر تولیدشده با هوش مصنوعی در اختیار پروژه قرار گرفته است.

## قرارداد دارایی‌ها

نام‌های پیشنهادی فایل‌ها و کاربرد آن‌ها:

- `store-hero.webp`: تصویر اصلی صفحه فروشگاه
- `storefront.webp`: نمای بیرونی فروشگاه
- `aisle-grocery.webp`: تصویر راهروی عمومی و قفسه‌ها
- `category-fruit.webp`: دسته میوه و سبزیجات
- `category-dairy.webp`: دسته لبنیات
- `category-bakery.webp`: دسته نان و شیرینی
- `category-cleaning.webp`: دسته شوینده و بهداشتی
- `shopping-bag.webp`: تصویر بسته‌بندی سفارش

## رفتار چندفروشگاهی مورد انتظار

1. تصاویر نمونه فقط fallback نمایشی پلتفرم هستند و نباید به‌عنوان عکس واقعی فروشگاه معرفی شوند.
2. هر tenant باید بتواند تصاویر اختصاصی خود را بارگذاری کند؛ تصویر اختصاصی همان فروشگاه بر تصویر پیش‌فرض اولویت دارد.
3. اگر تصویر اختصاصی ثبت نشده باشد، تصویر نمونه عمومی نمایش داده شود.
4. تصاویر کالا و دسته‌بندی که مدیر فروشگاه در پنل بارگذاری می‌کند، بر تصویر پیش‌فرض همان مورد اولویت دارند.
5. مالک فروشگاه باید فقط از عکس‌هایی استفاده کند که خودش تهیه کرده یا مجوز استفاده از آن‌ها را دارد.

## وضعیت

فایل‌های تولیدشده در بسته تحویلی `supermarket-demo-images.zip` قرار دارند. این مستند قرارداد نام‌گذاری و جایگزینی را ثبت می‌کند؛ اتصال فایل‌های باینری به مخزن و نمایش آن‌ها در رابط کاربری هنوز مرحله جداگانه‌ای است و نباید تا زمان ثبت فایل‌ها در مسیرهای دارایی پروژه، فعال‌شده تلقی شود.
